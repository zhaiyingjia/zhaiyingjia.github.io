# Yingjia Zhai — academic website

English-only, responsive, build-free GitHub Pages site. Open index.html locally to preview. No external libraries, fonts, analytics, or build tools are needed.

## Publish to the existing repository

1. Open https://github.com/sophiajia0922/sophiajia0922.github.io and select Add file → Upload files.
2. Upload index.html, style.css, portrait.jpg and .nojekyll to the repository root (not inside a site folder). Commit the files to the main branch. If existing files are present, review them before replacing them.
3. Open Settings → Pages. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
4. After the Pages deployment succeeds, visit https://sophiajia0922.github.io/ . Publication can take a few minutes. These instructions do not mean deployment has already occurred.
